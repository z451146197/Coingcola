# Coingcola 协作上下文

## 当前正式命名
- 一级菜单：开始使用 / 我的电脑 / 电脑优化 / 软件中心 / 关于
- 二级菜单：
  - 开始使用：首页 / WPS快捷键 / 管理常用网站
  - 我的电脑：电脑概览 / 详细配置 / 运行状态 / 更多信息
  - 电脑优化：一键优化 / 常用设置 / 常见修复 / 驱动与激活 / 高级设置
  - 软件中心：安装常用软件 / 软件目录 / 软件更新
  - 关于：程序简介 / 版本更新

## 当前稳定链路
- 常用设置：
  - 页面：让电脑更顺手视图
  - 兼容服务：电脑优化服务
  - 真实服务：系统设置服务
- 软件中心：
  - 页面：安装常用软件视图 / 查看全部软件视图
  - 兼容服务：软件中心服务
  - 真实服务：软件管理服务
