# COINGCOLA 首页预览落地稿

## 文件用途
本套文件用于替换或对照接入 `Resources/Web/Home/` 首页 Web 预览层。

## 文件清单
- `index.html`：纯 HTML 结构，无 Tailwind 依赖
- `styles.css`：独立样式文件
- `script.js`：基础交互脚本

## 当前口径
1. 已去除 React / Tailwind 依赖，适合 WebView 直接承载。
2. 首页按“左主区 + 右侧栏”布局输出。
3. 搜索态与首页态共用同一套容器骨架。
4. 网页导航保留编辑/删除的展示型交互。
5. 常用入口、最近使用、搜索结果、异常态、加载态均已内置。

## 接入建议
1. 先在独立浏览器中打开 `index.html` 验证视觉与结构。
2. 再替换项目内 `Resources/Web/Home/` 对应文件。
3. 若你项目内已有宿主层注入数据，可将 `script.js` 中的种子数据替换为宿主传值。
4. 若 WPF 外层已有统一背景与边距，可酌情减少 `page-shell` / `app-shell` 的 padding。
